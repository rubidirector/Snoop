# Snoop

남의 폰을 몰래 열어 보는 느낌의 인터랙티브 이야기 웹페이지예요.
잠금화면, 메시지, 톡, 사진, 검색 기록, 메모, 통화 기록, 캘린더가 있고, AI는 Google Gemini를 써요.
라이트 · 다크 모드, Google 로그인, 내 폰 목록, 배포(플레이 링크), 둘러보기, 총관리자 관리, 계정 탈퇴를 지원해요.

## 역할: 총관리자 · 관리자 · 사용자

| 역할 | 누구 | 할 수 있는 것 |
| --- | --- | --- |
| **총관리자** | `config.js`의 `superAdmins`와 `firestore.rules`의 `isSuper()`에 적힌 이메일 | 관리자 기능 전부 + 설정 › **총관리자**에서 모든 배포 보기, 둘러보기에서 내리기·올리기, 배포 중단 |
| **관리자** | Google로 로그인한 누구나 | 폰 꾸미기(컨셉·대화·🔒 시스템), 설정, 배포·배포 중단, 플레이 링크 복사 |
| **사용자** | 플레이 링크(`?play=...`)로 들어온 사람 | 폰 화면 보기와 대화만. 꾸미기·시스템·계정·폰 목록은 보이지 않아요 |

**배포하는 법 (관리자)**
1. 설정 › 내가 만든 폰 › 폰 옆 **배포** › **배포하기**
2. 나온 플레이 링크를 **복사**해서 보내요. `둘러보기 목록에도 올리기`를 켜면 둘러보기에도 보여요.
3. 배포한 뒤 고친 내용은 **고친 내용 다시 배포**를 눌러야 사용자에게 반영돼요. 다시 배포하면 사용자는 새 버전으로 처음부터 시작해요.
4. **배포 중단**을 누르면 링크가 더 이상 열리지 않아요. 폰 자체는 남아요.

**사용자 화면**
- 로그인 없이 바로 열려요. 위쪽 검은 섬(컴퓨터에서는 오른쪽 패널)에 이야기 설명, **설정**, **처음부터 다시 보기**가 있어요.
- 사용자 설정에는 AI 답장 키, 알림, 테마만 있어요.
- 사용자가 나눈 대화는 그 사람 기기에만 저장돼서, 다시 열면 이어서 볼 수 있어요.
- **API 키는 사람마다 각자 등록해요.** 관리자는 처음 열 때(또는 AI 기능을 처음 누를 때), 사용자는 플레이 링크를 처음 열 때(또는 키 없이 메시지를 보낼 때) **내 API 키 등록** 창이 떠요. 나중에 하려면 관리자는 설정 › 내 API 키, 사용자는 위쪽 검은 섬 › 내 API 키 등록(또는 설정)에서 할 수 있어요.
- 키는 그 사람 기기의 브라우저에만 저장되고 Google에만 보내져요. 관리자의 키는 배포 데이터에 들어가지 않아서 사용자에게 공유되지 않아요.
- 사이트에 `aiProxy`를 설정하면 키 등록 없이 사이트 주인의 키로 모두가 쓰게 바뀌어요(아래 선택 항목).

> 🔒 시스템 설정(인물 비밀 설정)은 사용자 화면에 보이지 않지만, AI가 답장할 때 쓰기 때문에 배포 데이터 안에는 들어 있어요. 브라우저 개발자 도구로 열어 보면 볼 수 있다는 점은 알아 두세요.

## 1단계. 사이트 올리기

GitHub Pages, Netlify, Cloudflare Pages, 일반 웹호스팅 어디든 폴더째 올리면 돼요. 이것만 해도 바로 쓸 수 있어요.
이 상태에서는 만든 폰이 각자 기기에만 저장되고, AI는 방문자가 **설정 › AI · API 관리**에 자기 Gemini 키를 넣어서 써요.

- 무료 Gemini 키: https://aistudio.google.com → Get API key

## 2단계. Google 로그인 · 공유 켜기 (Firebase, 무료 등급)

1. https://console.firebase.google.com 에서 **프로젝트 만들기** (Google 애널리틱스는 꺼도 돼요)
2. **빌드 › Authentication › 시작하기 › 로그인 방법 › Google** 을 사용 설정
3. **Authentication › 설정 › 승인된 도메인**에 내 사이트 주소 추가 (예: `myphone.netlify.app`)
4. **빌드 › Firestore Database › 데이터베이스 만들기** → 프로덕션 모드, 위치는 `asia-northeast3 (서울)`
5. Firestore의 **규칙** 탭에 `firestore.rules` 내용을 그대로 붙여 넣고 **게시** (배포 기능이 생기면서 규칙이 바뀌었어요. 예전 규칙을 쓰고 있다면 꼭 다시 게시하세요)
6. **프로젝트 설정(톱니) › 일반 › 내 앱 › 웹 앱 추가(</>)** → 나오는 `firebaseConfig` 값을 `config.js`의 `firebase:` 자리에 붙여 넣기

```js
firebase: {
  apiKey: 'AIza...',
  authDomain: '내프로젝트.firebaseapp.com',
  projectId: '내프로젝트',
  appId: '1:...:web:...'
},
```

이제 **설정**에서 이런 것들이 돼요.
- **Google로 로그인 / 로그아웃:** 만든 폰이 계정에 자동 저장돼서 다른 기기에서도 이어서 만들 수 있어요.
- **내가 만든 폰:** 폰 목록 보기, 열기, 새 폰 만들기(빈 폰 / 예시로 시작), 삭제
- **배포:** `배포하기` → `https://내사이트/?play=...` 플레이 링크가 생겨요. 위의 "역할"을 보세요. 예전 `?p=` 공유 링크도 사용자 화면으로 열려요.
- **계정 탈퇴:** 계정에 저장된 폰, 배포한 폰, 로그인 정보가 모두 삭제돼요.

> 카카오톡·인스타그램 같은 앱 안의 브라우저에서는 Google이 로그인을 막아요. 공유 링크 보기는 되지만, 로그인은 Safari나 Chrome에서 열어야 해요.
> 사진은 Firestore에 함께 저장돼요(별도 결제 설정 필요 없음). 무료 등급 한도는 Firebase 요금제 페이지에서 확인하세요.

## (선택) AI를 사이트 주인의 키로 제공하기

방문자가 키 없이 쓰게 하려면 서버가 필요해요.

- **Vercel:** 이 폴더를 GitHub에 올려 Vercel에서 가져오기 → Settings › Environment Variables에 `GEMINI_API_KEY` → `config.js`의 `aiProxy: '/api/gemini'`
- **내 서버 (Node.js 18 이상):** `GEMINI_API_KEY=내키 node server.js` → `aiProxy: '/api/gemini'`. IP 하나당 10분에 40번으로 제한돼요(`RATE_LIMIT`).

> 이 방식은 모든 방문자가 내 키 하나의 무료 한도를 나눠 써요. **API 키를 `config.js`나 다른 프론트엔드 파일에 넣지 마세요.**

## 꾸미기 화면

- **✦ AI 탭:** 컨셉으로 새 폰 만들기. 만들 항목(새 대화, 톡 친구, 사진첩, 검색 기록, 메모, 통화 기록, 일정)을 고를 수 있고, 새 폰이 하나 더 생겨요.
- **✦ AI로 다시 만들기:** 각 탭의 항목 맨 아래에 있어요. 이미 있는 내용을 이야기에 맞춰 새로 만들어요(한 번 더 눌러야 바뀌어요). 직접 올린 사진은 남아요.
- **기본:** 이름, 상황 소개, 등장인물 메모(AI 참고용), 날짜·시각·배터리, 잠금 비밀번호, 배경화면
- **대화·연락처:** 메시지·톡 목록마다 아래에 `+ 대화 추가`와 `✦ AI로 생성`이 있어요. 대화방을 열면 실제 채팅 화면처럼 보이고, 아래 입력창에 쓴 뒤 `◀ 상대가 보냄` / `내가 보냄 ▶`을 누르면 말풍선이 들어가요. 입력창 옆 칸에 보낸 시각을 넣을 수 있어요. 말풍선을 누르면 내용·시각 고치기, 순서 바꾸기, 보낸 사람 바꾸기, 삭제를 할 수 있고, `+`로 날짜 구분·사진·음성 메시지를 넣어요. 대화방 이름·프로필 사진·안 읽은 개수는 채팅 화면 맨 위에서 바로 고쳐요. 톡에서 멤버를 넣으면 단톡방이 되고, 보낸 사람을 골라서 말풍선을 넣어요. 톡 친구와 전화번호부(연락처)도 여기서 관리해요.
- **사진:** 사진 올리기, AI로 사진 설명 채우기, (유료 키) 실제 이미지 만들기
- **기록:** 검색 기록, 일정, 통화 기록, 메모. 입력하고 Enter를 누르면 목록에 올라가고, 항목마다 ✕로 지울 수 있어요.
- **🔒 시스템 (만든 사람만 보여요):** 주인공과 등장인물마다 성격, 말투, 관계, 비밀, 세계관, 숨은 진실, AI 규칙을 적어요. 보는 사람 화면에는 안 나오고, AI가 답장하거나 내용을 만들 때 참고해요.
  - **먼저 연락하기:** 켜면 보는 동안 등장인물이 먼저 메시지를 보내고 배너 알림이 떠요. 빈도(드물게·보통·자주)를 고르고, 인물마다 `먼저 연락할 확률`을 5% 단위로 적어요(0이면 안 함).
  - 공유된 폰에서 시스템 탭은 숨겨지지만, 데이터는 페이지와 함께 전달돼요. 개발자 도구까지 써서 보는 사람에게는 보일 수 있으니 진짜 비밀은 적지 마세요.

## 알림 · 시간 흐름

- **시간:** 폰을 처음 연 순간부터 폰 안의 시계가 실제 시간과 같은 속도로 흘러요. 페이지를 닫아도 계속 흘러서, 다시 열면 그만큼 지나 있어요.
- **알림 배너:** 먼저 오는 연락과 AI 답장이 오면, 앱 안 어느 화면에 있든 폰 위쪽에 알림 배너가 떠요. 누르면 그 대화방이 열려요.
- **알림 소리:** 설정 › 알림에서 켜고 끌 수 있어요. 소리는 코드로 만든 짧은 효과음이라 따로 파일이 없어요.
- **시스템 알림:** 설정 › 알림 › 시스템 알림 허용하기를 누르면, 페이지가 열려 있는 채 다른 탭이나 앱에 가 있을 때 기기 알림으로 와요. 아이폰·아이패드는 Safari 공유 버튼 › 홈 화면에 추가로 설치해야 해요.
- **페이지를 완전히 닫았을 때:** 이 사이트에는 서버가 없어서 닫혀 있는 동안은 알림을 보낼 수 없어요. 대신 다시 열면 닫혀 있던 시간만큼 도착했을 메시지가 한꺼번에 들어와요(최대 3통, 보낸 시각은 그때 시각으로 찍혀요). 닫혀 있을 때도 알림이 오게 하려면 푸시 서버가 따로 필요해요.

## 처음부터 다시 시작

폰 꾸미기 위쪽 버튼이나 폰 옆 패널의 **처음부터 다시 시작**을 누르면 폰을 열어 나눈 대화와 새로 도착한 메시지가 지워지고, 고친 내용이 반영돼요.

폰을 열어 대화하는 중에 **폰 꾸미기**를 열어 고치면, 고친 내용은 임시로 따로 쌓여요. 하던 대화는 그대로이고, 위쪽 **처음부터 시작** 버튼을 눌러야 폰에 반영돼요. 아무것도 안 고쳤으면 그 자리에 **닫기**가 보여요. 아직 폰을 열지 않았다면 바로 반영돼요.

## 알아둘 것

- Gemini 무료 등급에서는 보낸 내용이 Google 서비스 개선에 쓰일 수 있어요.
- 모델 이름은 Google이 종종 바꿔요. "모델을 찾을 수 없어요"가 뜨면 https://ai.google.dev/gemini-api/docs/models 에서 확인해 `config.js`를 고치세요.
- 휴대폰과 태블릿(아이패드 등)에서는 테두리 없이 화면 전체가 폰이 되고, 위쪽 검은 섬을 누르면 메뉴가 나와요. 안드로이드 뒤로 가기 버튼은 폰 안의 이전 화면으로 돌아가요.
- 톡 화면은 특정 메신저의 로고나 이름 없이 색감만 비슷하게 만들었어요.
- 파일로도 공유할 수 있어요: 설정에서 내보낸 `.json`을 영어 이름으로 `stories/`에 올리면 `?s=이름`으로 사용자 화면 링크가 돼요.
- 총관리자 이메일을 바꾸려면 `config.js`의 `superAdmins`와 `firestore.rules`의 `isSuper()` 두 곳을 같이 고치고 규칙을 다시 게시하세요.
